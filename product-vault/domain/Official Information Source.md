# Official Information Source

An approved authoritative source that the brand team may monitor and cite for public Ayurveda/health-policy information.

## Initial source register

| Source | Purpose | Allowed use |
| --- | --- | --- |
| Ministry of Ayush | Official initiatives, schemes, announcements and public resources | Curated factual summary + source link/attribution |
| Central Council for Research in Ayurvedic Sciences (CCRAS) | Official research/news/publication updates | Curated factual summary + source link/attribution |

## Rules

- Adding a source requires content/compliance approval and an accountable owner.
- Monitoring discovers candidate items only; it does not automatically publish, repost or make a product claim.
- Each published item stores the original URL, retrieval/source date, summary author, reviewer and publication/expiry status.
- If an official source corrects/removes an item, the editor reviews/unpublishes Srasveda’s summary promptly.
